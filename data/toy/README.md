# Toy Data

The files in this directory are lightweight CSV datasets designed for smoke-testing
the CEGVR skeleton. They are intentionally tiny so they can be versioned directly
within the repository and used in offline demonstrations.

- `budget.csv` – synthetic monthly budget entries used by the default configuration.
- `imbalanced.csv` – companion dataset for future experiments.

Feel free to replace these files with your own data when building out new demos.
