# Protocol template

`main.tex` describes the implemented candidate/solver interface and a proposed
evaluation. It contains no measured results. No published or peer-reviewed
paper is claimed. The former legacy PDF and untraceable result figures were
removed from the current branch; Git history retains them.

Build locally with `make` if a TeX distribution is installed. This only creates
a protocol document. Filling a results section requires completed raw model
run records and tables reproducibly derived from them, as specified in
[`../README.md`](../README.md). Old CSV table snippets are generator examples,
not evidence of completed evaluations.
