\subsection*{Linear main study}
The main paper path evaluates the candidate-first linear benchmark under five
explicit methods: \texttt{one\_shot}, \texttt{multi\_no\_feedback},
\texttt{multi\_generic\_feedback}, \texttt{multi\_unsat\_core\_feedback}, and
\texttt{cd\_vgs\_core\_rank}. The primary comparison concerns the four
compute-matched multi-round methods, which share identical \(K\), \(R\),
timeouts, parsing rules, and generation settings. The retry baselines differ
only in the carried-forward verifier feedback, while \texttt{cd\_vgs\_core\_rank}
uses the same fixed budget for conflict-directed candidate ranking and targeted
repair.

\paragraph{Metrics and comparisons.}
The run records expose verified solve rate, SAT certification rate, UNSAT
precision/recall, solver calls per certified solve, latency summaries, token
usage, and repair gain relative to \texttt{one\_shot}. Paired McNemar tests are
reported for solved-within-budget comparisons among the compute-matched methods,
with Wilcoxon signed-rank tests used for latency and solver-call comparisons.
