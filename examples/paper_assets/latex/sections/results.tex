\subsection*{Linear feasibility benchmark (LLM + SMT feedback)}
We evaluate a 500-instance linear corpus with mixed SAT/UNSAT labels. The
generator is LLM-backed and consumes SMT feedback: on UNSAT the solver returns
an unsat core which we render as hints (e.g., ``$y_1\!\le\!3$, $y_2\!\le\!2$, and
$(2)y_1\!+\!(2)y_2\!\ge\!11$ cannot hold together''), guiding subsequent proposals.
When a local LLM server is unavailable the CLI falls back to a stub generator.

Table~\ref{tab:main-linear} reports aggregate metrics. Accuracy and latency
curves appear in Figures~\ref{fig:budget_hist_linear}--\ref{fig:latency_linear}.
Under a tight budget, certification remains comparable to one-shot baselines
while latency increases with iteration depth; Section~\ref{tab:linear-compare}

\subsection*{Case studies}
We illustrate the feedback loop on a representative linear instance. An
unsatisfiable attempt returns the hints $y_1\!\le\!3$, $y_2\!\le\!2$, and
$(2)y_1\!+\!(2)y_2\!\ge\!11$, which cannot all hold together. The next prompt embeds
these conflicts; a revised assignment either satisfies all constraints or the
model returns an empty assignment signalling infeasibility. Similar behaviour
appears on Sudoku, where row/column/box conflicts become actionable guidance.
