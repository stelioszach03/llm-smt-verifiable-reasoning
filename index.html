Formal constraint checks.

CEGVR explores whether structured solver feedback helps a language model revise candidate solutions. It separates proposing an answer from checking the formal constraints that answer must satisfy.

Evidence status: the full experimental sweep's aggregate records are not included in this repository. This page does not display unverified accuracy, speedup or superiority claims. It is an explanation of the implemented pipeline, not a live model service.

How the loop works

  1. A configured generator proposes an assignment or structured trace.
  2. Z3 checks the candidate against the encoded constraints.
  3. The selected comparison arm supplies no feedback, generic feedback or constraint feedback for another attempt within a declared budget.
  4. The evaluation records outcomes and resource counters for later comparison.

A small illustrative example

Constraints: x + y = 5, x >= 0, y >= 0
Candidate:   x = 2, y = 4  → violates x + y = 5
Revision:    x = 2, y = 3  → satisfies these constraints

This hand-written example illustrates the interface. It is not generated by an LLM here and is not a measured research result. A solver checks the supplied mathematical encoding; it does not certify that a natural-language specification was translated correctly.

Reproduce the offline path

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pytest -q
cegvr eval --problems data/toy/problems.jsonl --out runs/toy \
  --seeds 1 --max-rounds 3 --budget 2 --timeout-ms 1500 --generator stub
cegvr summarize --runs runs/toy --table tables/toy/main_results.csv

The stub exercises parsing, the solver bridge and reporting without an external model endpoint. A full model experiment is a separate task requiring a configured inference server and its actual model identifier.

Scope

The tracked benchmark is synthetic linear arithmetic. The repository also contains small adapter examples, analysis tools and historical draft material. No publication, general reasoning guarantee, equal measured compute across every arm, or production deployment is claimed.
